# Snake Game

This is a simple Snake game built with JavaScript while I was learning web development and game logic from YouTube tutorials.

It is a beginner-friendly project and not entirely original work — it is inspired by classic Snake games and tutorial-based learning, with my own practice and understanding applied along the way.

## Features
- Classic Snake gameplay
- Keyboard controls
- Score tracking
- Game over detection
- Restart support
- Responsive and lightweight browser-based UI

## Project Note
This project was created as part of my learning journey, mainly following tutorial guidance while improving my understanding of JavaScript, DOM manipulation, and game development concepts.

## Technologies Used
- HTML
- CSS
- JavaScript
